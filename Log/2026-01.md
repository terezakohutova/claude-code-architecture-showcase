# Log - January 2026

### 2026-01-14 - CLOSED_Added style-guard hook after repeated superlative/em-dash violations in listing copy

Third time in two weeks a listing draft went out with a banned
superlative or an em dash despite the rule being documented in
`Feedback/no-marketing-superlatives.md` and re-read at the start of the
`product-listing` skill. Decided documented rules alone weren't holding
across sessions, so added `.claude/hooks/style-guard.js` as a `PreToolUse`
hook on `Write`/`Edit` - scans content for the banned phrase list and the
em/en dash characters, denies the write outright if either is found, with
the offending snippet quoted back.

Verified with a real `Write` call containing a deliberate violation - the
call was rejected before any file was touched. Nothing left open.

### 2026-01-08 - Set up inventory reference/status split and product-listing skill

Inventory notes had been one flat growing file - split into
`Inventory/inventory-reference.md` (maker/material/condition facts, rarely
change once an item is logged) and `Inventory/inventory-status.md`
(listing status per item: draft, live, sold - changes constantly). Wrote
`.claude/skills/product-listing/SKILL.md` as a checklist for turning a
logged item into a listing, referencing both files. Open for next time:
decide whether sold items get archived out of `inventory-status.md` or
just marked, once there are enough of them to make the file noisy.
